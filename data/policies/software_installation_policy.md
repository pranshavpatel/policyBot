# Software Installation Policy

See also Device Policy for general device management, and Data Security Policy for third-party tool review.

## 1. Approved Software
- Software listed in the internal Software Catalog can be self-installed on company-managed laptops without additional approval.
- Anything not in the catalog requires a request to IT and, if it will store or process company data, a Security review (see Data Security Policy).

## 2. Browser Extensions
- Browser extensions requesting access to page content or cookies require IT approval before installation.

## 3. Open-Source and Package Managers
- Developers may install open-source packages via approved package managers (npm, pip, etc.) for development purposes without individual approval, subject to the company's standard dependency-scanning tooling.

## 4. Prohibited Software
- Peer-to-peer file sharing tools, cryptocurrency mining software, and unlicensed/pirated software are prohibited on all company devices.

## 5. Personal Devices
- Personal devices enrolled under BYOD are subject to the same catalog rules for any app accessing company email or data.

## 6. Requesting New Software
- Submit a request via the IT portal; typical turnaround for review is **5 business days**.
